# Foyer Raccolta Differenziata

Integrazione per Home Assistant che conosce il calendario della raccolta differenziata di
casa: calcola cosa passano a ritirare, ricorda quando esporre i sacchi e lo mostra in
card dedicate.

**Stato: in progettazione.** Non c'è ancora codice installabile. La specifica è in
[docs/SPEC.md](docs/SPEC.md).
